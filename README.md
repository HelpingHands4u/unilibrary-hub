# UniLibrary Hub

Build UniLibrary — Discover. Learn. Grow. (based on https://github.com/HelpingHands4u/unilibrary.git). Make the reserve buttons and every button related to books work smoothly without external server configuration errors: book reservations, borrowing and issuing, renewals, returns, fine tracking, wishlists, user reviews, search and filters, and student/librarian role workflows.

This project was built with [Lovable](https://lovable.dev).
